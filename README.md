# 在 Magpie 里用 Dim

## 这个插件能做什么？

让你在 [Magpie](https://github.com/yetone/magpie) 里直接用 Dim 套餐里的模型。装好后登录 Dim 账号，就能选模型、看用量、重置额度，也能打开官网购买或续期套餐。

## 怎么安装？

先确认一下，你的 Magpie 是 **0.1.2818 或更新版本**。

打开 Magpie 的 **Plugins（插件）** 页面，点击 **Add a plugin（添加插件）**，填入：

```text
arcships/magpie-dim-oauth
```

点确认，等 Magpie 把插件装好就行。

习惯用终端的话，也可以直接执行：

```sh
magpie plugin add arcships/magpie-dim-oauth
```

## 装好以后，怎么开始用？

1. 在 Magpie 的服务商列表里找到 **Dim OAuth**，点击 **国内站登录**。
2. 浏览器会打开登录页，用你的 Dim 账号登录并同意授权。
3. 回到 Magpie，等模型列表出来，给你正在用的 Agent 选一个 Dim 模型，就可以开始用了。

```text
Magpie
├─ 模型选择 → Dim OAuth → 选择套餐里的模型
└─ Dim 账户 → 看用量 / 重置额度 / 购买与续期
```

## 可以用哪些模型？

看你当前账号和套餐开通了哪些。登录后，Magpie 会加载能用的模型，直接从列表里选就行。

## 在哪里看用量和套餐到期时间？

打开侧栏的 **Dim 账户**，就能看看套餐什么时候到期、额度用了多少，以及还要等多久才会重置。想看最新情况，点右上角的 **刷新**。

## 额度用完了，可以手动重置吗？

可以，只要你的账号里还有对应的重置次数。在 **Dim 账户** 里可以选：

- **重置用量窗口**：把当前套餐的用量窗口清零。
- **恢复月度额度**：把当前计费月的套餐额度恢复到满额。

点进去后，先看看要重置的是哪个套餐、还剩几次、什么时候到期。确认没问题，再点 **消耗 1 次并重置**。还没想好就点取消，不会扣次数。

## 重置时网络出了问题，再试一次会重复扣次数吗？

在原来的确认框里点重试就好，同一次操作不会因为重试而重复扣次数。

## 没有套餐，或者想续期，去哪里？

想买套餐或者续期，点账户页里的 **购买套餐** 或 **续期套餐**，浏览器就会打开 Dim 官网。想先看看价格，也可以点 **查看价格**。

你也可以直接 [购买或续期套餐](https://dimagent.cn/console/subscription)，或者先 [查看价格](https://dimagent.cn/console/pricing)。

买好或续期后，回到 **Dim 账户** 点一下 **刷新**，就能看到更新后的套餐了。

## 登录没完成，或者登录后没看到模型，怎么办？

如果还没完成授权，回到 Magpie 再点一次 **国内站登录**，跟着浏览器里的提示完成登录。

已经登录了的话，先刷新一下 Dim OAuth 的用量，再打开 **Dim 账户** 看看。

## 为什么重置按钮点不了？

看看当前有没有可重置的套餐，以及对应的次数是不是用完了。窗口重置和月度额度恢复各用各的次数。

## 远程用 Magpie，为什么购买页面没在自己电脑上打开？

按钮打开的是运行 Magpie 那台机器的浏览器。把账户页里的套餐链接复制出来，在自己的浏览器里打开就行。
